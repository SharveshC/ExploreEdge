# 🌍 ExploreEdge - Travel Planner 
ExploreEdge is a modern, responsive travel planner website designed to help users discover, compare, and plan trips across multiple destinations. With an emphasis on user experience, it offers curated travel packages, destination insights, and smooth, intuitive navigation.

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Design: Responsive layouts, modular components
- Tools: VS Code, Git, GitHub

## ✨ Key Features
- Browse curated travel destinations with rich media content
- View detailed travel packages including itineraries and pricing
- Responsive design optimized for desktop, tablet, and mobile
- Smooth and interactive navigation across all pages
- “Add to Cart” feature for saving preferred destinations

## 🚀 Future Improvements
- Integrate backend for real-time bookings and data storage
- Add search, filter, and sort functionality for packages
- Implement map-based navigation using Google Maps API
- Enable user reviews, ratings, and personalized recommendations
- Improve accessibility, multi-language support, and performance

## 📸 UI / UX Preview Ideas
- Homepage showcasing top attractions with hero banners
- Destination pages with pricing, images, and day-wise itineraries
- Interactive cart and wishlist for selected destinations
- Contact forms, feedback forms, and newsletter signup
- Fully responsive mobile and tablet layouts

## 💻 Getting Started Locally
1. Clone the repository: git clone https://github.com/SharveshC/ExploreEdge.git
2. Navigate to the project folder: cd ExploreEdge
3. Open index.html in your browser to view the website locally

## 🧩 Project Structure
- **ExploreEdge/**
  - `index.html` – Homepage
  - `destinations.html` – Destination listings
  - **css/**
    - `style.css` – Stylesheet
  - **js/**
    - `main.js` – JavaScript file
  - **assets/** – Images, icons, and media files


## 🤝 Contribution

1. Fork the repository

4. Make your changes and test thoroughly
