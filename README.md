# 🏞️ Explore Edge - Comprehensive Travel & Tourism Platform

Explore Edge is a feature-rich travel and tourism web application designed to provide users with a seamless experience for discovering, exploring, and booking travel destinations and packages. The platform focuses on showcasing the beauty of various locations including Coimbatore, Ooty, Valparai, and more, with an emphasis on user experience and interactive features.

## ✨ Key Features

### 🗺️ Destination Exploration
- **Interactive Destination Pages**: Detailed pages for various destinations with high-quality images and descriptions
- **Category-based Browsing**: Explore destinations by categories like Heritage, Adventure, Wildlife, and more
- **Local Experiences**: Discover unique local experiences and activities at each destination

### 🎒 Travel Packages
- **Pre-designed Tour Packages**: Curated travel packages with detailed itineraries
- **Customizable Options**: Flexible package customization based on preferences
- **Special Interest Tours**: Themed packages for adventure, heritage, wildlife, and more

### 🔐 User Experience
- **Responsive Design**: Fully responsive layout that works on all devices
- **Interactive UI/UX**: Smooth animations and transitions powered by AOS (Animate On Scroll)
- **User Authentication**: Secure login and registration system with password recovery
- **Shopping Cart**: Integrated cart system for package bookings

### 📝 Interactive Elements
- **Review System**: Users can leave and read reviews for destinations and packages
- **Vehicle Booking**: Integrated vehicle rental system for local transportation
- **Contact Forms**: Easy-to-use contact forms for inquiries and support

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, or Edge)
- Code editor (VS Code, Sublime Text, etc.)
- Git (for version control)

### Installation

1. **Clone the repository**:
   ```bash
   git clone [repository-url]
   cd Explore_Edge_Frontend-main
   ```

2. **Run the application**:
   - Simply open `Homepage/index.html` in your preferred web browser
   - For development, consider using a local server (e.g., Live Server in VS Code)

3. **Explore the website**:
   - Browse destinations
   - View package details
   - Test the booking flow
   - Explore different sections
